# Mobile Strategy & Institutional Features

## 1. Mobile (PWA · ≥ 375px)

- Sidebar collapses into a bottom-tab nav (5 items: Dashboard, Macro, Sectors, Agent, More)
- Top KPI grids: 4-col → 2-col on mobile
- Charts: reduce to 200px height, hide EMA50 by default, swipe between timeframes
- Stock detail: tab-bar between Overview / Chart / Agent / Setup / News
- AI Agent: full-screen chat; suggested prompts as horizontal scroll chips
- Add to Home Screen prompt after 3 sessions
- Push notifications via PWA for regime change and watchlist alerts
